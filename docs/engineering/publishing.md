# publishing

github.io 仅发布确认 HTML 和必要公开资源，使用专用静态仓库；不上传源码、PRD 或准备记录。读取 services.json 目标，按 ai-coding-development/implementation/publishing.md 验证实际 URL、资源和本人体验。

先明确是原型展示、源码备份还是CloudBase正式作品，分别核绑定和授权，不改旧remote。Pages副本固定index.html/.nojekyll并保留资源路径，拒绝控制字符文件名；提交后等待真实部署终态，核线上commit/内容/资源，再给网址。失败先定位授权、资源路径或平台等待，不强推覆盖未知内容。

CloudBase正式发布使用固定镜像本轮Web产物；管理工具按现有官方授权执行。部署后真实会话验证登录、数据/图片和权限，不能拿Pages展示或管理员SQL代替。发布/迁移超时先查当前终态，不立即重发写操作。目标、源码/产物摘要、实际URL和缺项记录到当前进度。
