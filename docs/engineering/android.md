# android

调用 ai-coding-android。沿用 appId 和同一 Web 工程，在绑定镜像内编译、cap sync、Gradle 构建。产物记录路径/hash/版本/源码摘要/镜像身份；安装、启动、本人试用和同步另验。

默认 Capacitor webDir=dist，入口以实际配置为准；多入口/独立手机布局须来自确认需求，不能临场默认另造移动站。固定镜像路线使用其兼容Capacitor/JDK/Gradle/SDK，不临时升级Capacitor或在宿主补4GB工具。

本轮spec写清“更新哪些当前Web交互→同步哪套环境/身份配置→图标与版本→Web build→cap sync→Gradle→APK内容核验→安装试用”。不能只跑Gradle；旧资源错误按链定位，不以文件存在/版本号正确代替内容。图标设计已确认时核实际包内图标，未确认不凭空设计；保持原appId/签名以延续更新与数据。

云共享时复用本项目环境/身份并核手机↔网页；本地作品不强制云登录。原生打印/拍照等只按本轮要求实现，核当前插件/权限/线程要求；构建不能代替真机能力验证。
