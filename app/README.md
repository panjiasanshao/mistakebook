# 学海灯塔 · 错题本

孩子专用单机错题本：截图/拍照录入错题，3D 翻转卡片闭卷自测与掌握状态流转，A4 双栏重练组卷打印，本地数据备份恢复。数据全部保存在本机浏览器 IndexedDB，断网可用。

## 功能模块

- 错题库：统计卡片、搜索与学科/错因/状态筛选、3D 翻转卡片自测
- 录入错题：Ctrl+V 粘贴截图、拖拽/上传图片自动压缩、元数据与错因标签
- 重练组卷：组卷篮勾选、A4 双栏排版预览、打印/存 PDF、文末答案附录
- 设置中心：5 套配色主题、JSON 备份导出与导入恢复、存储概览

需求与设计材料见 `docs/design/`（v1.md 需求文档、v1.html 原型），进度记录见 `docs/progress/`。

每一轮先说清功能目标，更新 PRD 与原型并确认后交给 Trae 分步实现与测试，再亲自验收、记录反馈。后续增加云端、安卓或 AI 功能也用同一流程。

当前容器工具：Docker Desktop。在作品根目录运行 `docker compose up -d --wait` 启动，起始网页 http://localhost:5189 。
