# 我的作品

这是刚创建的空白工作空间。每一轮先说清功能目标，在 Gemini 新建或更新 需求说明文档.md，在 Canvas 更新并试用设计，确认后交给 Trae 分步实现与测试，再亲自验收、记录反馈。后续增加云端、安卓或 AI 功能也用同一流程。课程工具不预设业务、登录方式或 AI 功能。

项目名称和用途可以在需求与原型设计确认后补充，现在无需填写。

当前容器工具：Podman CLI + 独立 Docker Compose。由助手经用户级 Course-Runtime.ps1 的固定 provider/connection 在作品根目录运行 `podman compose up -d --wait`，由助手检查起始网页。
